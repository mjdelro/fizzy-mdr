# Icon Sources

Fizzy MDR vendors only the SVG geometry required by the theme. No icon package, CDN request, icon font, or runtime icon JavaScript is required.

## Interface icons

The interface icon partials in `partials/icons/` are standardized on the Lucide icon family and use the theme's `currentColor` stroke styling. Lucide is released under the ISC License.

Used for: archive, home/house, link, location/map pin, search, star, tag/tags, moon, and sun.

Source: https://lucide.dev/
License: https://lucide.dev/license

## Brand icons

GitHub, Facebook, Twitch, Ko-fi, and X use Simple Icons SVG geometry. Simple Icons data is released under CC0-1.0; brand names and marks remain trademarks of their respective owners and should be used in accordance with applicable brand guidelines.

Source: https://simpleicons.org/
License: https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md

LinkedIn uses the Bootstrap Icons LinkedIn SVG because LinkedIn is not distributed by current Simple Icons releases. Bootstrap Icons is released under the MIT License.

Source: https://icons.getbootstrap.com/icons/linkedin/
License: https://github.com/twbs/icons/blob/main/LICENSE.md

The Creative Commons license marks in the footer remain official Creative Commons assets and are not part of this icon-partial set.
