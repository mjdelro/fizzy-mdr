# Anti-Slop & Theme Optimization Audit 001 (2026-11-25)

Target: `fizzy-mdr` (`v3.1.11`, commit `d27236f`)
Direction source: `DESIGN.md` (`ENERGY 1 / RHYTHM 2 / MOTION 1`)
Validation run: `gscan` Ghost 6.x (`PASS`), `contrast-check.py` WCAG 2.x verification, static template/CSS/JS analysis.

## Findings

### HIGH Priority (Hard Gate)

1. **[HIGH] (R-34) Ghost live accent color is overwritten by stylesheet cascade order:** `default.hbs:39-44` injects inline `:root { --site-accent: {{@site.accent_color}}; --site-accent-contrast: {{contrast_text_color @site.accent_color}}; }` before `default.hbs:59` loads `assets/css/custom.css:1-8`, whose `:root` block redeclares `--site-accent: #176b3a` and `--site-accent-contrast: #fff` at equal specificity and clobbers Ghost Admin settings.
2. **[HIGH] (R-25, R-34) Multiple dark-mode text and control pairings fail WCAG AA contrast:** `contrast-check.py` confirms `assets/css/custom.css:576` `--accent-readable` (`#4e8a65`) scores `4.13:1` on dark page (`#1c1d20`) and `3.81:1` on dark card (`#222428`), `custom.css:577` `--link-color-hover` (`#3a7a53`) drops lower on hover, `custom.css:383` `.post-list-card-tag` (`#709d80` on `#20312b`) scores `4.44:1`, `custom.css:581,585` `--text-muted` (`#8a8d94`) on `--surface-elevated` (`#292b30`) scores `4.26:1` (all `< 4.5:1`), and `custom.css:774` `.header-control:hover` (`#176b3a` on `#222428`) scores `2.37:1` (`< 3.0:1` non-text contrast).
3. **[HIGH] (R-39) Post archive injects invalid `<hr>`, `<h2>`, and `<h4>` children into `<ul>` and skips `<h3>`:** `assets/js/main.js:58-70` inserts `<hr>`, `<h2>`, and `<h4>` directly inside `<ul class="post-archive">` (`custom-post-archive.hbs:21`), violating HTML5 list structure and skipping `<h3>`; `custom-post-archive.hbs:19` also caps results at `limit="100"` while reporting total post count, and `custom-post-archive.hbs:27` hides featured post status from screen readers (`title` attribute only with `aria-hidden` SVG).
4. **[HIGH] (R-03) Compact controls miss the `44x44px` minimum touch target on mobile and coarse pointers:** `assets/css/custom.css:1599-1609` sets mobile `.carousel-pip` to `24x36px` (`gap: 2px`) and `.carousel-nav-button` to `36x36px`, while `.post-list-card-tag` (`custom.css:365`, ~`24px` tall) has no `@media (pointer: coarse)` hit-area expansion promised in `DESIGN.md:77,104,152`.
5. **[HIGH] (R-39, R-32) ARIA and link markup silence card content, misuse roles, and duplicate keyboard Tab stops:** `custom-tag-archive.hbs:25` puts `aria-label="View posts tagged {{name}}"` on the outer card `<a>`, hiding its inner `<h2>`, description, and post count from assistive tech; `partials/footer.hbs:46` applies prohibited `aria-label` to `<p class="cc-icons">`; `partials/header.hbs:2,21-52` uses redundant `role="navigation"` on `<nav>` and duplicate `aria-label` + `.is-sr-only` labels; and `partials/list_card.hbs:4` plus `partials/post/post_card.hbs:4,39` create duplicate Tab stops per story card instead of marking secondary image/avatar links `tabindex="-1" aria-hidden="true"`.
6. **[HIGH] (R-39) Base CSS misses universal `cursor: pointer` / `cursor: not-allowed` rules and incomplete `prefers-reduced-motion` suppression:** `assets/css/base.css:82,293,455` omits `cursor: pointer` on native `button`, `summary`, `select`, `label[for]`, and `[role="button"]` and omits `cursor: not-allowed` on disabled controls, while `assets/css/custom.css:2164-2177` disables motion on only 9 selectors, leaving transitions active on `.skip-link`, `.kg-file-card-container`, `.post-list-card-tag`, `#toc a`, `.tag-directory-card`, and `assets/css/main.css:546,947-969,1184`.
7. **[HIGH] (R-26, R-27) Homepage showcase and post archive lack empty-state / single-slide guards:** `partials/showcase.hbs:8-44,46-77` renders empty `.showcase-carousel` boxes with dead prev/next `<button>` controls when 0 or 1 `#carousel` post exists and an empty `.showcase-featured` box when 0 featured posts exist, and `custom-post-archive.hbs:19-33` lacks an `{{else}}` empty state.
8. **[HIGH] (R-40) Render-blocking CSS waterfall, missing UI font preload, unsized images, N+1 tag-mosaic queries, and unconditional post/footer external fetches:** `default.hbs:46-59` makes 4 separate render-blocking CSS requests (`fonts.css`, `base.css`, `main.css`, `custom.css`) without preloading primary UI/heading font `atkinson-400.woff2`; `partials/header.hbs:9`, `author.hbs:13`, `partials/post/post_author.hbs:9-11`, and `custom-tag-archive.hbs:31` omit intrinsic `width`/`height` or `aspect-ratio`; `custom-tag-archive.hbs:19-37` runs up to 100 nested `{{#get "posts"}}` N+1 queries loading `600px` (`size="medium"`) images for tiny 2x2 thumbnails; `default.hbs:54-57` loads KaTeX CDN CSS on every post regardless of math content; and `partials/footer.hbs:47-50` fetches 4 external Creative Commons SVGs on every page load.

### MEDIUM Priority (Purpose-Gate)

9. **[MEDIUM] (R-19, R-03) Legacy `transition: all` animations and `100vh` sizing violate motion and mobile viewport budgets:** `assets/css/main.css:546,947,951,969,1184` animates `all` over `250ms`-`500ms` (exceeding `DESIGN.md:142` `150ms`-`180ms` transform/opacity budget) and `assets/css/custom.css:1926` uses `max-height: calc(100vh - 7.5rem)` without `100dvh` fallback.
10. **[MEDIUM] (R-03, R-04) Mobile navigation uses a bare unlabeled burger icon and ignores outside clicks:** `partials/header.hbs:28-32` hides mobile navigation behind an unlabeled three-line icon without visible text affordance, and `assets/js/main.js:21-47` does not close the open mobile menu when tapping outside `#navbar`.
