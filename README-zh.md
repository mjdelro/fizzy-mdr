# Fizzy MDR

Fizzy MDR 是基于 Yuzhang Huang 的 Fizzy Theme 修改并维护的 Ghost 6 主题。

当前版本：**2.4.0**

2.3.0 主要进行代码整理与重构，不包含有意的视觉重新设计。2.3.4 进一步统一了图标系统：界面图标使用本地 Lucide SVG partial，品牌图标使用本地 Simple Icons SVG partial（LinkedIn 使用 Bootstrap Icons），不增加运行时图标库依赖。2.3.5 将深色模式的页面、卡片、搜索和代码等表面调整为中性的黑色与灰色，仅保留绿色作为强调色，以避免影响照片、电影截图和打字机图片的视觉色彩。2.3.6 尝试保留 Ghost 图片与图库说明文字中的换行；2.3.7 新增明确的 `\n` 标记，可在前端可靠转换为真正的换行。完整文档请参阅 [README.md](./README.md)。 2.3.11 改进目录（TOC）的滚动跟踪与点击高亮，使快速来回导航时当前章节能立即同步。2.4.0 进一步统一了页眉圆形控制、分类标签、卡片尺寸、阴影、圆角和特色图片居中规则，并清理了重复与过时的样式。
